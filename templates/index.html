About JA4 Fingerprints

JA4 is a network fingerprinting method that identifies TLS clients based on their handshake characteristics. Use this tool to identify applications, detect anomalies, and investigate potential threats.

  • JA4: TLS client fingerprinting
  • JA4H: HTTP client fingerprinting
  • JA4S: TLS server fingerprinting
Example: t13d1516h2_8daaf6152771_b0da82dd1658
Enter up to 100 fingerprints, one per line

🔌 API Access

Programmatic access available via REST API:

GET /api/lookup/<fingerprint>

Example:

curl http://localhost:5000/api/lookup/t13d1516h2_8daaf6152771_b0da82dd1658

CLI Tool: For power users, use python3 ja4lookr.py --help
